## Publicar el manual de usuario

Lo publica el flujo `.github/workflows/manual-usuario.yml`, que sube **solo**
la carpeta `manuales/usuario/`. Una sola vez, en GitHub:

**Settings › Pages › Build and deployment › Source: GitHub Actions**

Desde entonces se publica solo cada vez que cambia esa carpeta, o a mano en
**Actions › Publicar manual de usuario › Run workflow**.
